# Scripts

This folder contains utility scripts for inspecting, validating, and visualizing project artifacts.

## Files

- `inspect_pth.py`
  Print top-level structure of a `.pth` artifact.

- `summarize_results.py`
  Summarize CSV/PTH result files in a folder.

- `plot_psd_sample.py`
  Plot a single PSD example from a saved `.pth` file.

- `validate_artifacts.py`
  Check tracked sample artifacts for obvious issues such as missing PSD entries.

- `plot_training_history.py`
  Plot training/validation curves from a saved training checkpoint.
