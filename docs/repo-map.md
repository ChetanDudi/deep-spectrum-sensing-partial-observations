# Repository Map

## Core code

- `hardware/pu_transmitter/`
  GNU Radio transmitter assets for the Primary User side.

- `hardware/su_receiver/`
  GNU Radio receiver flowgraph, custom PSD logger, and synthetic dataset generation script.

- `simulation/`
  Synthetic dataset generation from measured PSD libraries.

- `models/`
  Starter recurrent model definitions.

- `training/`
  Baseline training and evaluation scripts for generated datasets.

- `scripts/`
  Utility tools for inspecting `.pth` and `.csv` artifacts.

- `notebooks/`
  Quick exploratory notebook material.

## Supporting material

- `docs/`
  High-level project explanation, hardware/data flow, reproducibility notes, and repository map.

- `data/`
  Sample captured PSD artifacts plus ignored runtime/generated data directories.

- `docs/assets/`
  Submitted report and presentation files.
