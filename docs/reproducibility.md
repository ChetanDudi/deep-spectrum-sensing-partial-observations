# Reproducibility Guide

## Goal

This repository now includes a lightweight reproducible workflow for:

1. collecting PSD captures
2. generating synthetic datasets from those captures
3. training starter recurrent models on the generated data
4. evaluating saved checkpoints

## Recommended workflow

1. Start from the modulation-specific PSD libraries already in `data/sample_results/`.
2. Run `simulation/single_pu_su_to_multi_pu_su_dataset.py` to generate a new dataset snapshot.
3. Record the generated dataset path and timestamp.
4. Train one or more recurrent baselines using `training/train.py`.
5. Save metrics and checkpoints under `checkpoints/` and `runs/`.
6. Use `training/evaluate.py` and the plotting utilities to compare outputs.

## What to record for each experiment

- dataset file path
- random seed
- model type
- hidden size
- number of recurrent layers
- batch size
- learning rate
- number of epochs
- train/validation split

## Included starter config

- `configs/train_config.json`

This config is intentionally simple so it can be edited without introducing more dependencies.

## Important caveat

The training code added in this cleanup pass is a baseline scaffold derived from the dataset format described in the report and generated by `single_pu_su_to_multi_pu_su_dataset.py`. It is meant to make the repository runnable and understandable; it is not a claim that these exact training scripts are the original ones used in the reported experiments.
